# Seva App 🙏

> **Note:** This project was developed during my internship. Due to confidentiality, the original source code cannot be shared. This repository documents my role, contributions, and the technologies I used.

## 📱 Project Overview

The **Seva App** was built for a spiritual organization to manage seva (service) submissions and participation tracking.
The app allows users to:

* Submit and track seva activities
* View upcoming participation events
* Manage user authentication and secure access
* Get real-time updates through Firebase

## 🛠️ Tech Stack

* **Frontend:** Flutter (Dart)
* **Backend:** Firebase (Authentication, Firestore Realtime Database)
* **APIs:** REST API integrations
* **Other Tools:** Provider/Bloc for state management

## 👨‍💻 My Contributions

* Created the full **seva submission & participation tracking flow** in Flutter
* Integrated **Firebase Authentication** for user login/signup
* Connected **Realtime Database** for live seva updates
* Focused on **clean UI/UX** for an intuitive user experience
* Optimized performance for **smooth, reliable usage**
